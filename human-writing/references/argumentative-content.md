# 论证型内容框架

## 适用范围

当内容承担解释、说服、复盘、教学或辅助判断的任务时，使用本框架。以下题材默认属于论证型内容：

- 行业分析、商业分析、产品分析和政策／研究解读
- 观点文章、方法论文章、知识型公众号和财经内容
- 项目复盘、案例研究、职场经验和教程
- 从长文拆出的论证型短视频或口播

纯故事、人物特写、游记、情绪随笔和文学创作不强制使用。混合题材可以把本框架作为底层结构，正文仍按人物、场景或时间推进。

## 核心目标

让读者沿着一条可验证的推理链获得判断：

> 读者问题 → 核心判断 → 形成机制 → 分类证据 → 适用边界 → 行动建议 → 新认识

七个环节是论证功能，不要求机械写成七章。短内容可以合并环节，但不得省略核心判断和支持它的证据。

## 强制工作流

### 1. 定义读者问题

先写清楚目标读者正在判断什么、困惑什么或准备采取什么行动。汇报材料把领导关切视为读者问题；公众号和视频把受众的现实问题视为读者问题。

### 2. 确定一个核心判断

全文只推进一个主要结论。核心判断必须具备被反驳的可能性，能够用一句完整的话表达。只有主题词、口号或正确但空泛的共识，不算核心判断。

### 3. 解释形成机制

回答事情为什么发生、各因素如何作用。避免从现象直接跳到结论。机制不确定时，明确标为合理推断，并写出仍需验证的环节。

### 4. 把材料组织成三到五组证据

先广泛阅读和收集，再围绕核心判断筛选。把零散信息归入三到五个有意义的方向，不按检索顺序或材料来源顺序堆放。无法支持论证的材料可以舍弃。

每个论证单元采用以下结构：

> 分论点 → 一至两个事实／案例／数据 → 对事实的解释 → 与核心判断的关系

只有分论点、没有事实支撑的段落必须补证据或删除。只有事实、没有解释的段落必须说明这些事实证明了什么。

### 5. 交代适用边界

主动处理反面证据、例外情况、证据不足和结论失效条件。说明确定知道的、合理推断的和仍不确定的内容。边界用于提高判断精度，不单独制造翻案效果。

### 6. 给出行动建议

把分析转成读者可以执行的动作、判断标准或下一步验证。建议必须由前文论证推出，避免在结尾突然增加未经论证的新方案。

### 7. 用新认识收尾

结尾完成合成：把前面的机制、证据和边界压缩成一个新的认知坐标。避免逐条复述全文。

## 材料处理规则

- 读材料时尽量宽，写正文时严格收窄，只保留能够推动论证的内容。
- 引用外部材料时，以作者自己的问题和框架为主。外部观点只能作为局部证据。
- 前后重复的内容删除；孤立观点补论据；孤立事实放入能够证明的分论点下。
- 十几项行动或事实应分类为三到五个方向。分类后的可理解性高于表面全面。
- 代表性强的项目可以单独展开为案例，用来提高论证的具体程度和影响力。

## 平台适配

### 汇报和报告

使用以下映射：任务要求 → 如何理解 → 如何部署和行动 → 取得什么结果 → 哪些案例最有代表性 → 下一步怎么做。总论点通常回答工作是否得到有效落实，以及证据是否充分。

### 公众号和长文

开头先交付阅读收益并提出核心判断；正文依次解释机制、组织证据、处理边界；结尾给出行动和新认识。小标题写判断，避免只写市场概况、原因分析、案例分享等主题标签。

### 短视频和口播

每条只承载一个核心判断或一个分论点。压缩为：明确收益／问题 → 判断 → 一个机制或案例 → 一个边界 → 一个行动。证据不足时，不靠情绪化措辞弥补。

## 验收清单

交付前逐项检查：

1. 读者问题是否具体？
2. 全文是否只有一个主要判断？
3. 判断是否解释了形成机制？
4. 每个分论点是否至少有一个可核查事实、案例或数据？
5. 材料是否被归入三到五个方向，而非顺序堆积？
6. 是否说明了结论的适用边界和不确定性？
7. 行动建议是否由前文论证自然推出？
8. 收尾是否形成了新的认识，而非重复摘要？

任意第 2、4、6 项不通过，论证型内容不得定稿。
